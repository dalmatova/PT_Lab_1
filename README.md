# Лабораторная работа №1

## Определение операционной системы и сбор её параметров

### Описание

Программа определяет операционную систему, на которой запущена, и собирает информацию о компьютере и Python. Все полученные данные записываются в файл result.json.

Программа рассчитана на работу в Windows, Linux и macOS.

### Используемые модули

В работе использовались стандартные модули Python:

- `platform` — информация об операционной системе и процессоре.
- `os` — работа с путями и получение количества процессоров.
- `sys` — информация о Python.
- `json` — запись данных в JSON-файл.
- `shutil` — получение информации о диске.
- `datetime` — получение даты и времени.

### Какие данные собираются

- Название и версия операционной системы.
- Архитектура и информация о процессоре.
- Количество процессоров.
- Версия и реализация Python.
- Общий, занятый и свободный объём диска.
- Дата и время сбора информации.

### Запуск программы

Для запуска нужен установленный Python.

В терминале нужно выполнить команду:

```powershell
python my_script.py
```

После запуска в папке с программой создаётся файл result.json, в котором сохраняется собранная информация.
